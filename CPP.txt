# Operetor in cpp
========================================================================================================
1. Arithmetic Operators
Arithmetic Operators
 ├── Binary
 │    ├── Addition (+)
 │    ├── Subtraction (-)
 │    ├── Multiplication (*)
 │    ├── Division (/)
 │    └── Modulus (%)
 └── Unary
      ├── Unary Plus (+)
      ├── Unary Minus (-)
      ├── Increment (++)
      └── Decrement (--)
========================================================================================================
2. Assignment Operators
       [ Assignment Operators ]
           │
           ├─ Basic & Arithmetic ───┬─ =   (Simple Assignment)
           │                        ├─ +=  (Add Assignment)
           │                        ├─ -=  (Subtract Assignment)
           │                        ├─ *=  (Multiply Assignment)
           │                        ├─ /=  (Divide Assignment)
           │                        └─ %=  (Modulus Assignment)
           │
           └─ Bitwise & Shift ──────┬─ &=  (Bitwise AND Assignment)
                                    ├─ |=  (Bitwise OR Assignment)
                                    ├─ ^=  (Bitwise XOR Assignment)
                                    ├─ <<= (Left Shift Assignment)
                                    └─ >>= (Right Shift Assignment)
========================================================================================================
3. Relational / Comparison Operators
├── Equality Operators
│   ├── ==  (Equal to)
│   └── !=  (Not equal to)
│
├── Value Comparisons
│   ├── <   (Less than)
│   └── >   (Greater than)
│
└── Boundary Comparisons
    ├── <=  (Less than or equal to)
    └── >=  (Greater than or equal to)

========================================================================================================
4. Logical Operators
Logical Operators
 │
 ├── AND (&&)
 │
 ├── OR (||)
 │
 └── NOT (!)
========================================================================================================
5. Bitwise Operators
Bitwise Operators
 ├── & (Bitwise AND)
 ├── | (Bitwise OR)
 ├── ^ (Bitwise XOR)
 ├── ~ (Bitwise NOT / Complement)
 ├── << (Left Shift)
 └── >> (Right Shift)
========================================================================================================
6. Miscellaneous / Other Operators
 ├── sizeof -------- [Returns the size of a data type or variable]
 ├── ternary (?:) -- [Conditional operator acting as a shortcut for if-else]
 ├── comma (,) ----- [Separates expressions and executes them sequentially]
 ├── member -------- [Accesses structure or class members]
 │    ├── dot (.)
 │    └── arrow (->)
 ├── pointer ------- [Handles memory addresses and references]
 │    ├── address-of (&)
 │    └── dereference (*)
 └── type ---------- [Manages type checking and conversions]
      ├── typeid
      └── cast (static_cast, dynamic_cast)
